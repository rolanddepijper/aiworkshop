# AI Workshop

OpenEdge ABL project demonstrating the Business Entity Architecture Pattern, populated from ProjectGengar's Step-16 branch.

## Structure

- `src/` - ABL source (business entities, UI windows)
- `src/business/` - Business entity classes and dataset includes
- `doc/` - Architecture documentation
- `dump/` - Database schema definition
- `.windsurf/` - Windsurf rules and workflows
